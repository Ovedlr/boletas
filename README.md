# Boletería Barakah

Plataforma de venta de boletas de la Corporación Cultural y Artística Barakah.

- Página pública: https://ovedlr.github.io/boletas/
- Panel de administración: https://ovedlr.github.io/boletas/#/admin
- Modo portería (control de ingreso): https://ovedlr.github.io/boletas/#/porteria

El archivo `index.html` contiene toda la página. Las claves y los datos de los compradores
no están aquí: viven en el servidor de Google Apps Script (`Codigo.gs`) de la cuenta de Barakah.
